# FourthFingerPkg (EDK2)

A UEFI application (built as an EDK2 boot application) that provides a shell program used to explore the system via the UEFI API in the pre-boot environment.

## Purpose

- Explore UEFI/EDK2 pre-boot execution flow
- Experiment with early initialization behavior
- Learn build and execution workflow of EDK2 packages

## Components

- Custom EDK2 package configuration
- Makefile-based build integration
- Early-stage boot experimentation code
